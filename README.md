# New_project5
This is my project for the sprint 5.
Este aplicativo web cria dois tipos de gráfico com base num conjunto de dados sobre anúncios de venda de carros.
No aplicativo web você tem duas opções de visualizações gráficas: um histograma que analisa a quilometragem dos veículos e gráficos de dispersão com relação preço/quiloemtragem.

Link para o projeto: https://new-project5.onrender.com
